# ㅌㅗㅇ 해석 모드 (Claude Code)

lazzzyResearch처럼 내 컴퓨터의 Claude Code로 통계 결과 해석 초안을 쓰는 폴더입니다. Claude Pro 이상 요금제가 필요합니다.

1. ㅌㅗㅇ → 결과 해석 메뉴 → **[Claude Code]**에서 `CLAUDE.md`와 `interpretation.json`을 받아 새 폴더에 넣습니다.
   (여기 있는 `CLAUDE.md`는 예시입니다. 연구 설계(횡단·종단·실험)에 따라 규칙 문장이 달라지므로 사이트에서 받는 것을 쓰세요.)
2. **Claude 데스크톱 앱**(https://claude.ai/download) → 위쪽 **Code** 탭 → **Local** → **Select folder**로 그 폴더를 열고 "해석해 줘"라고 씁니다. 터미널이 필요 없습니다. (터미널이 익숙하면 그 폴더에서 `claude`를 실행해도 됩니다.)
3. 의도 확인 질문에 답하면 `draft.md`가 생깁니다.
4. 초안을 결과 해석 메뉴의 **[초안 점검]** 칸에 붙여 넣어 숫자·판정·표현을 점검합니다.

자세한 설치 방법은 사이트의 [사용 설명 → Claude Code로 맡기기 (폴더 방식)]에 있습니다.
