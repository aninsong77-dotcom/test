# 차원 이동 · 돔 꾸미기 예시 (사이트에는 아직 안 넣음)

- `seoul-sky.html`: 서울 상공 돔 예시 (맑은 하늘, 흰 구름, 한강, 다리, 보트, 사람, 차, 남산타워·롯데타워 느낌)
- `earth-orbit.html`: 지구를 바라보는 우주 돔 예시 (푸른 은하수, 반짝이는 별, 운석, 떠오르는 해, 유리 바닥 가장자리)
- `green-floor-square-cushions.js`: 은은한 초록 바닥 + 파스텔 사각 방석(좌복) 예시. 바다 돔은 지금 모습을 유지하기로 했고, 서울 상공 돔에 쓸 수 있게 보관
- `img/`: 예시 그림들

## 서울 상공 돔 (실제 지도) — 이어서 할 때 참고

- `seoul-real/index.html`: 예시 장면 전체 (한강·도심 지도, 랜드마크, 궁궐, 건물·차·나무, 하나로 이은 길, 실제 시간의 해·달·별·밤 불빛)
- `seoul-real/data.json`: OSM 자료를 줄인 장면 자료 (약 0.55MB). 출처 표시 필요: © OpenStreetMap contributors (ODbL)
- `seoul-real/prep.py`: OSM GeoJSON 두 개(한강, 도심) → data.json 변환
- 정해진 것: 길은 하나로 잇기(여의도→한남대교→남산→도심 한 바퀴→남산→잠실, 편도 약 34km, 끝에서 되돌아옴), 시간 변화는 서울 실제 해·달 위치, 바닥은 가장자리 유리
- 남은 일: 속도 정하기, 사이트 index.html에 차원으로 붙이기(차원의 문, 차원별 사람 나누기, 들어갈 때만 불러오기, 폰 가벼운 모드), 끝 화면 출처에 OSM 표시

## 차원이동 — 정해진 것 (1단계)

- 버튼 이름: **차원이동** (하단 버튼 줄). "시간이 다르게 흐르는 공간"으로 가는 느낌
- 누르면 갈 곳 고르기: 바다 · 서울 하늘 · 지구 우주
- **누른 자리(아바타 바로 앞)에 둥근 차원의 문**이 생김: 영화 속 포털처럼 빛나는 고리가 소용돌이치고 안쪽은 물결처럼 울렁임, 안으로 갈 차원의 하늘빛이 어른거림
- 아바타가 걸어 들어감 → 화면이 물결치며 바뀜(소리 잠깐 늘어짐, 빛 알갱이 천천히) → 새 돔의 같은 문에서 걸어 나오고 문이 닫힘
- 차원별로 사람 나누기: presence에 차원 정보(dim) 한 줄 추가, 같은 차원 사람만 보임, 다른 차원은 사람 수만 표시. Firebase 규칙 변경 필요 없음
- **9시 함께 명상은 모든 차원에서 동시에**, 종치기 명상은 같은 차원끼리
- 순서: ① 차원이동(문, 나누기, 서울은 임시 배경) → ② 서울 돔(seoul-real 예시 옮기기, 들어갈 때만 불러오기, 폰 가벼운 모드, OSM 출처) → ③ 지구 우주 돔(earth-orbit 예시)
