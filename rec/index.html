컴퓨터 소리를 녹음할 때 (컴퓨터 소리만, 컴퓨터 + 바깥 소리)

  1. 녹음 시작을 누르면 "공유할 항목 선택" 창이 떠요.
  2. 위쪽에서 전체 화면을 고르고 화면 그림을 한 번 눌러요.
  3. 아래쪽 시스템 오디오도 공유를 켜요. 이걸 안 켜면 소리가 녹음되지 않아요.
  4. 공유를 누르면 바로 녹음이 시작돼요.
  • "화면 공유 중" 막대가 뜨지만 화면은 저장하지 않고 소리만 저장해요. 막대의 공유 중지를 눌러도 녹음이 끝나고 저장돼요.
  • 녹음하는 동안 이 창은 최소화는 괜찮지만 닫으면 안 돼요. 혹시 닫혀도 그때까지 녹음된 건 아래 목록에 남아요.
  • 전체 화면을 고르면 컴퓨터에서 나는 소리가 전부 녹음돼요. 알림음은 꺼 두세요.
  • 유튜브 소리만 깔끔하게 받고 싶으면, 공유 창 위쪽에서 Chrome 탭(엣지는 탭)을 고르고 유튜브 탭을 누른 뒤 탭 오디오도 공유를 켜세요. 그 탭 소리만 녹음돼요.
  • 컴퓨터 + 바깥 소리는 이어폰을 쓸 때 추천해요. 스피커로 들으면 마이크가 스피커 소리를 한 번 더 받아서 울릴 수 있어요.
  • 바깥 소리만은 공유 창 없이, 처음 한 번 "마이크 사용 허용"만 누르면 돼요.
  • 노트북이라면 녹음 중에 절전 모드로 들어가지 않게 전원을 연결해 두세요.
  • 크롬이나 엣지에서 써 주세요.

내 녹음

아직 녹음이 없어요.

녹음은 이 컴퓨터의 브라우저 안에만 저장되고 인터넷에 올라가지 않아요. 브라우저의 인터넷 사용 기록(사이트 데이터)을 지우면 녹음도 함께 지워지니, 중요한 녹음은 파일로 저장해 두세요. 수업을 녹음하기 전에는 강사·학교 규정을 확인해 주세요.
