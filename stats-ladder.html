설문 설계 사용 설명

변인마다 문항과 응답 선택지를 적으면, 구글 폼을 만드는 스크립트와 코드북이 만들어집니다.

표본 수 계산 사용 설명

가설을 검증하려면 최소 몇 명이 필요한지 계산합니다. 계산 근거는 연구계획서에 그대로 쓸 수 있습니다.

모델 검토 사용 설명

설문을 배포하기 전에 연구 모형을 한 번 더 따져 보고 가설을 확정합니다. 여기서 고친 것은 기록만 남고 흠이 되지 않습니다.

응답 취합·정리 사용 설명

구글 폼 응답을 넣으면 설문 설계대로 숫자로 바꾸고, 역문항을 뒤집고, 중복·이상치·빠진 값을 찾아 정리한 뒤 변인 점수를 만듭니다.

1. 응답 넣기

  1. 스크립트 실행 로그의 응답 시트 링크를 엽니다. (또는 구글 폼 [응답] 탭 → [Sheets에서 보기])
  2. 시트 메뉴에서 [파일 → 다운로드 → 쉼표로 구분된 값(.csv)]을 누릅니다.
  3. 받은 파일을 아래 [CSV 파일 고르기]로 넣습니다. 시트를 전체 복사(Ctrl+A, Ctrl+C)해 붙여 넣어도 됩니다.

시트를 '웹에 게시'하지 마세요. 링크를 아는 누구나 응답을 볼 수 있게 됩니다. 응답이 더 들어오면 다시 받아서 넣으면 됩니다.

🔒 응답 원자료는 이 브라우저 안에서만 처리합니다. 저장하거나 밖으로 보내지 않아서, 페이지를 닫으면 다시 넣어야 합니다.

표본 확인 사용 설명

몇 명이 왜 빠졌는지, 계획한 인원을 채웠는지 보고, 연구 대상자의 특성 표(표 1)를 만듭니다.

측정 점검 사용 설명

척도가 믿을 만한지(신뢰도), 재려는 것을 제대로 재는지(타당도)를 확인합니다.

사전 분석 사용 설명

가설을 검증하기 전에 점수의 분포(정규성), 변인 간 상관(표 2), 다중공선성을 확인합니다.

분석 사용 설명

응답 취합에서 만든 변인 점수로 가설로 정한 기법을 계산합니다. 계산은 모두 이 브라우저 안에서 합니다.

결과 해석 사용 설명

연구 의도를 적으면 AI가 먼저 이해한 내용을 확인하고, 코드가 내린 가설 판정과 계산된 숫자 그대로 결과·논의 초안을 씁니다.
