    설문 설계 사용 설명

    변인마다 문항과 응답 선택지를 적으면, 구글 폼을 만드는 스크립트와 코드북이 만들어집니다.

    응답 취합 사용 설명

    구글 폼 응답을 넣으면 설문 설계대로 숫자로 바꾸고, 역문항을 뒤집고, 변인 점수와 신뢰도를 만듭니다.

    1. 응답 넣기

    1. 스크립트 실행 로그의 응답 시트 링크를 엽니다. (또는 구글 폼 [응답] 탭 → [Sheets에서 보기])
    2. 시트 메뉴에서 [파일 → 다운로드 → 쉼표로 구분된 값(.csv)]을 누릅니다.
    3. 받은 파일을 아래 [CSV 파일 고르기]로 넣습니다. 시트를 전체 복사(Ctrl+A, Ctrl+C)해 붙여 넣어도 됩니다.

    시트를 '웹에 게시'하지 마세요. 링크를 아는 누구나 응답을 볼 수 있게 됩니다. 응답이 더 들어오면 다시 받아서 넣으면 됩니다.

    🔒 응답 원자료는 이 브라우저 안에서만 처리합니다. 저장하거나 밖으로 보내지 않아서, 페이지를 닫으면 다시 넣어야 합니다.

    분석 사용 설명

    응답 취합에서 만든 변인 점수로 사다리가 고른 기법을 계산합니다. 계산은 모두 이 브라우저 안에서 합니다.

    결과 해석 사용 설명

    연구 의도를 적으면 AI가 먼저 이해한 내용을 확인하고, 코드가 내린 가설 판정과 계산된 숫자 그대로 결과·논의 초안을 씁니다.

    사용 설명통계 사다리 위키

    검증 기록

    실제 논문의 설계를 사다리에 넣어 보고, 나온 기법이 논문의 기법과 같은지 적어 두세요.

    #논문 이름고른 경로나온 기법논문의 기법일치 여부메모

    기록은 이 브라우저에만 저장됩니다. 다른 기기로 옮기거나 보관하려면 CSV로 내려받으세요(엑셀에서 열림).

    근거 꼬리표별 규칙 목록

    첨부 자료 없이 통계 지식으로 채운 AI 지식 규칙입니다. 하나씩 확인하고, 자료가 생기면 근거 위치를 채워 주세요.

    통계 사다리 시제품 · 갈림길 규칙은 이 파일 안 rules-data 부분에 따로 들어 있습니다.
