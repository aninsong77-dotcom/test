# 테스트

통의 계산이 R과 같은지, 경계 상황에서 결과가 틀어지지 않는지 확인합니다. 코드를 고칠 때마다 돌립니다.

```
cd tests
npm install                  # 처음 한 번 (Playwright)
npx playwright install chromium   # 브라우저가 없으면
node reference.mjs           # R 기준값 + 화면 → R 대조 (Rscript 필요, 없으면 1부만)
node edge.mjs                # 경계 상황 (R 필요 없음)
```

## reference.mjs
- **1부** (R 없이 됨): `reference_values.json`에 R로 미리 계산해 둔 값과 통의 계산 함수를 비교합니다.
  - t검정 (Student·Welch, 챗GPT 리뷰의 예시 포함)
  - 회귀: 보통 자료, 단위가 아주 다른 자료, 완전 공선성
  - 피어슨 r, Shapiro–Wilk
  - 요인분석: 주성분, 주축요인추출 (psych `fa(fm = "pa")`와 같은 반복)
  - 베이즈 인자: t, 상관, 회귀. BayesFactor 패키지의 공개값(sleep 자료 17.25888) 포함
- **2부** (Rscript 필요): 예시 자료로 화면에서 분석 23가지를 돌립니다. 병렬매개, 조절, 조절된 매개 Model 7·14도 들어갑니다. 그다음 통이 만든 `analysis.R`을 R로 실행해 효과 78개의 추정값, p, 신뢰구간을 비교합니다. 부트스트랩 신뢰구간은 R과 난수가 달라 0.02까지 허용합니다. 결과 그래프(일곱 종류)가 그려지는지와 PNG 받기도 확인합니다.

기준값을 새로 만들려면 `Rscript make_reference.R`을 실행합니다(기본 R만 사용).

## edge.mjs
2026년 10월 외부 점검에서 재현된 문제가 다시 생기지 않는지 봅니다. 점검자가 만든 보고서형 스크립트를 통과/실패 판정으로 옮겼습니다.
- 응답 정리
  - 동의 문항이 없는 설문에서 '동의'형 척도 응답을 비동의로 빼지 않음
  - 중복 응답은 기본으로 빼지 않고 제출 간격을 보여 줌
  - 타임스탬프 읽기, CSV 수식 막기
- 계산이 안 되는 자료: 로지스틱 분리, 공분산분석·편상관의 공선성, 점이연에서 한 집단만 남음 → 한국어 안내
- 매개분석에서 X가 두 집단이면 부분표준화 효과
- 사다리: 단일표본·대응·반복측정·분류 결과 기법 뒤에 매개·조절이 붙지 않음 (모든 경로 전수 조사)
- 사다리: 세 집단 이상·기준 2가지 이상을 지나온 공분산분석 뒤에도 매개·조절이 붙지 않음
- 가설 붙여 넣기
  - 매개: "M은 X와 Y의 관계를 매개할 것이다", "M은 X가 Y에 미치는 영향을 매개할 것이다"
  - 조절: "W에 따라 X가 Y에 미치는 영향이 다를 것이다", "W가 높을수록 X가 Y에 미치는 영향은 약해질 것이다"
  - 조절된 매개: "간접효과는 W에 따라 달라질 것이다", "…W에 의해 조절될 것이다", "W는 X가 M을 매개로 Y에 미치는 간접효과를 조절할 것이다"
  - 안전장치: 읽은 변인 이름에 문장 조각이 남으면 "확인해 주세요"로 표시하고 완성으로 두지 않음
  - 세 집단 이상인 원인·조절 변인은 매개·조절 계산 불가를 안내
  - 매개 카드에 합친 회귀 가설의 표시와 [따로 분석하기]
- 클리닝: 주의 확인 문항, 같은 번호 연속, 역문항 모순, 연구 대상 조건, 값 정리(숫자·같은 뜻·범주 합치기), 직접 빼기, 연구 대상 절 문장
- [가설 전부 계산하기]: 가설마다 계산, 같은 분석은 한 번만, 다시 눌러도 다시 계산하지 않음, 결과 해석에서 가설과 자동 연결
